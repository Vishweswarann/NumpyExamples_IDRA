# NumPy Practice Exercises - Day 6

This file accompanies the `NumpyExercise_Day6.ipynb` Jupyter Notebook. 

**Note:** This notebook was created solely for practice and foundational skill-building in NumPy.

## Topics Covered

The notebook acts as a hands-on walkthrough of essential NumPy concepts. Here is what is included:

*   **1D Array Creation:** Building foundational arrays using functions like `np.array`, `np.arange`, `np.linspace`, and randomized generation.
*   **Multi-Dimensional Arrays:** Reshaping flat data and generating matrices and 3D arrays using `np.ones`, `np.full`, and `np.random.randint`.
*   **Array Properties:** Inspecting the underlying structure of the data using `.ndim`, `.shape`, `.size`, and `.dtype`.
*   **Indexing and Slicing:** Extracting specific elements and subsets from both 1D and multi-dimensional arrays, including advanced step-slicing.
*   **Boolean Masking:** Filtering arrays conditionally (e.g., finding evens, filtering by range) and dynamically replacing values that meet specific criteria.
*   **Aggregating Functions with Axes:** Calculating maximums, means, and sums along specific dimensions (`axis=0`, `axis=1`, `axis=2`).
*   **Concatenation & Clipping:** Merging multiple arrays together and using `np.clip()` to bound array values within a strict numerical range.

## Usage
Since this is a practice environment, feel free to modify the cells, change the axis parameters, or break things to see how the NumPy engine responds!
